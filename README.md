# .github

The profile and default community files of the
[OpenYardage](https://github.com/openyardage) organisation on GitHub.

| Path | What it holds |
|---|---|
| `profile/README.md` | The text on the organisation's page. |
| `CODE_OF_CONDUCT.md`, `SUPPORT.md` | Defaults for every repository that has none of its own. |
| `.github/ISSUE_TEMPLATE/` | Issue forms and their `config.yml`, for every repository without its own. |

A repository that needs something else keeps its own file; GitHub then
ignores the default. With issue forms this goes for the whole folder: one
form or a `config.yml` in a repository replaces everything here.
