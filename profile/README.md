# OpenYardage

[OpenYardage](https://openyardage.com) makes yardage books from
OpenStreetMap and open elevation data: distances, hazards and elevation
hole by hole, free to print.
Here are the projects we develop in the open.

## Projects

| Project | What it is |
|---|---|
| [OpenPinsheet](https://github.com/openyardage/openpinsheet-api) | The format, the API server and the tools for an open data set of golf pin positions by date and hole, under the Open Database License. |
| [OpenPinMarker](https://github.com/openyardage/openpinmarker) | Plans for an open device that measures the pin position from the flagstick and reports it to OpenPinsheet. |

## Get involved

- Questions, wrong data and ideas: open an issue in the project's
  repository. Its `CONTRIBUTING.md` says what helps most.
- A green, bunker or hole in the wrong place on OpenYardage comes from
  OpenStreetMap. [Fix it there](https://www.openstreetmap.org/fixthemap);
  OpenYardage picks the change up with its next data update.
- Security problems: report them privately, as the repository's
  `SECURITY.md` describes, otherwise at info@openyardage.com. Never in a
  public issue.
- Questions about your own club: clubs@openyardage.com
- Everything else: info@openyardage.com
